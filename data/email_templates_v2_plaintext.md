## Что изменилось vs v1

| Параметр | v1 (HTML) | v2 (Plain Text) |
|----------|-----------|-----------------|
| Формат | HTML таблицы, CSS, base64 img | Plain text |
| Размер | ~33KB | ~1KB |
| Ссылки | Через emikss.host (redirect) | Нет ссылок в теле (только подпись) |
| Логотип | Base64 PNG в HTML | Нет |
| Трекинг | emikss.host pixel + click | Нет (трекинг — через Mail.ru отчёты) |
| Gmail категория | PROMOTIONS | PRIMARY (inbox) |
| Доставляемость | Низкая | Высокая |

## Правила рассылки (без изменений)

1. **Не больше 50 писем в день** (чтобы не попасть в спам)
2. **Персонализация**: подставлять {company_name} в тему и текст
3. **Отправка**: будни, 10:00–14:00
4. **Follow-up**: через 3–4 дня, если нет ответа
5. **Стоп-лист**: если ответили «не интересно» — больше не писать
6. **Порядок**: сначала киты (46), потом IT (1054), потом экспортёры (2711)
7. **Формат**: ТОЛЬКО plain text для первого касания
8. **HTML шаблон (v1)**: использовать только для КП (по запросу клиента)

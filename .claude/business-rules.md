# Business Rules - FirstClass Automation

## Фазы проекта

### Фаза 1: Аудит процессов (текущая) ✅

**Статус:** 100% готов

**Цель:** Собрать данные о текущих процессах турагентства

**Компоненты:**
- Web-panel для анкет (fc-audit.vercel.app)
- 4 анкеты для разных ролей
- Дневник времени
- n8n workflow → Telegram уведомления

**KPIs:**
- [ ] Все 4 анкеты заполнены
- [ ] 5-7 дней дневника времени собрано
- [ ] Выявлены top-3 узких места

---

### Фаза 2: Интеграция Union ↔ 1С (4-6 недель)

**Цель:** Автоматизировать передачу данных из Union в 1С

**Варианты:**
1. n8n workflow (рекомендуется)
2. Python/JS скрипт
3. Готовое решение

**KPIs:**
- [ ] Время обработки документа: 15 мин → 2 мин
- [ ] Ошибки ручного ввода: 0

---

### Фаза 3: Telegram Bot для лидов (2-3 недели)

**Цель:** Квалификация и роутинг входящих запросов

**Функции:**
- Квалификация: B2C или B2B?
- Роутинг: Даша (B2C) или Паша (B2B)
- Уведомления менеджерам
- Сохранение контакта

**KPIs:**
- [ ] Время ответа на лиды < 5 минут
- [ ] 0 потерянных заявок

---

### Фаза 4: CRM (3-4 недели)

**Цель:** Единая база клиентов и воронки продаж

**Варианты:**
1. Bitrix24 (рекомендуется для РБ)
2. amoCRM

**Интеграции:**
- Telegram Bot → CRM (автосоздание лида)
- WhatsApp → CRM
- Сайт fclass.by → CRM

## Роли в команде

### Даша (B2C менеджер)

**Функции:**
- Работа с частными клиентами
- Instagram продажи
- Консультации по турам

**Метрики для аудита:**
- Количество обращений/день
- Конверсия в продажу
- Среднее время закрытия сделки
- Повторные продажи

---

### Паша (B2B менеджер)

**Функции:**
- Корпоративные договоры
- Командировки и тимбилдинг
- Работа с юрлицами

**Метрики для аудита:**
- Количество корпоративных клиентов
- Средний чек B2B
- Retention rate

---

### Бэкофис

**Функции:**
- Документооборот в Union
- Оформление туров
- Связь с туроператорами

**Метрики для аудита:**
- Время обработки документа
- Количество ошибок
- Загруженность по дням

---

### Бухгалтер

**Функции:**
- Учет в 1С
- Обработка квитанций
- Сверки с туроператорами

**Метрики для аудита:**
- Время на ручной ввод
- Количество документов/день
- Проблемы интеграции Union→1С

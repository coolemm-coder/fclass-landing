# Skill: Self-Improve Memory

## Description

Обновляет память проекта на основе новых знаний и проблем.

## Trigger

Используй этот skill когда:
- Столкнулся с неочевидной проблемой
- Принял решение с альтернативами
- Нашел reusable паттерн
- Изменил архитектуру

## Instructions

### Self-Check вопросы (в конце сессии)

1. **Потерял ли я время на что-то, что можно было предотвратить?**
   - Да → Добавь в `gotchas.md`

2. **Принимал ли решения с альтернативами?**
   - Да → Документируй в `decisions.md`

3. **Узнал ли что-то, что пригодится в будущем?**
   - Да → Запиши в `learnings.md`

4. **Изменилась ли архитектура системы?**
   - Да → Обнови `architecture.md`

### Форматы записей

#### gotchas.md

```markdown
### Короткое название проблемы

**Проблема:** Описание

**Симптом:** Как проявляется

**Решение:** Как исправить

**Статус:** ⚠️ Требует исправления / ✅ Решено
```

#### decisions.md

```markdown
## YYYY-MM | Название решения

**Контекст:** Почему возникла необходимость

**Альтернативы:**
1. Вариант А — плюсы/минусы
2. Вариант Б — плюсы/минусы

**Решение:** Выбранный вариант

**Причины:** Почему выбрали именно это

**Trade-offs:** Чем пожертвовали
```

#### learnings.md

```markdown
## Название паттерна

### Контекст
Когда применять

### Код/Пример
```html/css/js
...
```

### Примечания
Особенности, edge cases
```

### Файлы памяти

| Файл | Путь |
|------|------|
| gotchas | `.claude/memory/gotchas.md` |
| decisions | `.claude/memory/decisions.md` |
| learnings | `.claude/memory/learnings.md` |
| architecture | `.claude/memory/architecture.md` |

## Output

После обновления памяти, сообщи:
- Какой файл обновлен
- Что добавлено (1-2 строки)
- Почему это важно запомнить

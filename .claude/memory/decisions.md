# Decisions Log - FirstClass Automation

## ADR-001 | Vercel vs Beget для Frontend
- **Дата:** 2026-01
- **Решение:** Vercel для frontend, Beget для n8n
- **Причина:** Бесплатный CDN, auto-deploy, SSL

## ADR-002 | n8n для Webhook обработки
- **Дата:** 2026-01
- **Решение:** n8n workflow (не custom script)
- **Причина:** Визуальное редактирование, сервер уже есть

## ADR-003 | Telegram для уведомлений
- **Дата:** 2026-01
- **Решение:** Telegram (primary), Google Sheets (архив)
- **Причина:** Мгновенно, удобно, клиент в Telegram

## ADR-004 | Фон секций лендинга
- **Дата:** 2026-02-07
- **Решение:** Единый #e2e6eb для всех секций кроме "О нас" (navy)
- **Причина:** После 5 итераций с пользователем. Серый фон + белые карточки = современный вид
- **Альтернативы:** Белый фон (слишком плоско), чередование (слишком пёстро), тёмный (перегружено)

## ADR-005 | Кнопки — solid filled
- **Дата:** 2026-02-07
- **Решение:** Залитые кнопки (gold nav CTA, white hero, dark form submit)
- **Причина:** Лучше конверсия чем transparent/outlined
- **Альтернатива:** Outline buttons — выглядят элегантнее но хуже кликают

## ADR-006 | SEO-first подход
- **Дата:** 2026-02-07
- **Решение:** Schema.org, мета-теги, canonical URL до запуска рекламы
- **Причина:** Органический трафик бесплатен, индексация занимает время

## ADR-007 | Google Sheets как стартовая CRM
- **Дата:** 2026-02-07
- **Решение:** Google Sheets + n8n (не Bitrix24 сразу)
- **Причина:** Бесплатно, быстро, достаточно до 50 клиентов
- **Когда мигрировать:** При 10+ заявках/неделю перейти на Bitrix24

## ADR-008 | Яндекс.Карты вместо Google Maps
- **Дата:** 2026-01-30
- **Решение:** Яндекс.Карты для embed на лендинге
- **Причина:** Популярнее в Беларуси, проще embed

## ADR-009 | Vanilla JS (без фреймворков)
- **Дата:** 2026-01
- **Решение:** Vanilla JS + Tailwind CDN (не React/Vue)
- **Причина:** Простые формы, быстрая загрузка, нет сборки

## ADR-010 | Система сессий для самообучения
- **Дата:** 2026-02-07
- **Решение:** .claude/sessions/YYYY-MM-DD.md после каждой сессии
- **Причина:** Контекст теряется между сессиями, нужен structured logging

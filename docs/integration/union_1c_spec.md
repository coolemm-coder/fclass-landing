# Спецификация интеграции Union ↔ 1С

> Статус: ЧЕРНОВИК (требуется аудит)
> Версия: 0.1
> Дата: 2026-01-30

---

## Обзор

### Цель
Автоматическая передача данных о бронированиях из системы Union в 1С:Бухгалтерия.

### Текущий процесс (AS-IS)
```
Union (бронирование)
    ↓ [ручной экспорт / просмотр]
Бэкофис
    ↓ [ручной ввод / Excel]
Бухгалтер
    ↓ [ручной ввод]
1С:Бухгалтерия
```

**Проблемы:**
- 5-10 часов/неделю ручной работы
- Ошибки при вводе
- Расхождения данных
- Задержки в учете

### Целевой процесс (TO-BE)
```
Union (бронирование)
    ↓ [автоматический экспорт]
n8n (трансформация)
    ↓ [проверка + импорт]
1С:Бухгалтерия
    ↓
Уведомление бухгалтеру
```

## Архитектура решения

### Компоненты

```
┌─────────────┐     ┌──────────┐     ┌──────────┐
│   Union     │────▶│   n8n    │────▶│   1С     │
│  (источник) │     │ (логика) │     │  (цель)  │
└─────────────┘     └──────────┘     └──────────┘
      │                   │                │
      ▼                   ▼                ▼
  API/Export         Transform          Import
  Schedule           Validate           Notify
                     Map fields
```

### n8n Workflow

```
1. Trigger (Cron: каждые 15 мин / по событию)
        ↓
2. Fetch from Union (HTTP Request / DB Query)
        ↓
3. Filter new/updated bookings
        ↓
4. Transform & Validate
        ↓
5. Map to 1С format
        ↓
6. Push to 1С (COM-объект / HTTP / Файл обмена)
        ↓
7. Log result
        ↓
8. Notify (Telegram / Email)
```

## Варианты подключения

### Union

**Вариант 1: API (если есть)**
- Прямой запрос данных
- Real-time или по расписанию
- Требуется: API-документация, ключ

**Вариант 2: База данных**
- Прямое подключение к БД Union
- SQL-запросы
- Требуется: доступ к БД, структура таблиц

**Вариант 3: Экспорт файлов**
- Union экспортирует в CSV/Excel
- n8n забирает файлы
- Менее гибко, но просто

### 1С

**Вариант 1: COM-объект (Windows)**
- Прямое управление 1С
- Максимальная гибкость
- Требуется: Windows-сервер с 1С

**Вариант 2: Web-сервис 1С**
- REST/SOAP API
- Требуется: публикация сервиса в 1С

**Вариант 3: Файл обмена**
- n8n создает файл (XML/JSON)
- 1С импортирует через обработку
- Просто, но с задержкой

**Вариант 4: EnterpriseData**
- Стандартный формат обмена 1С
- Хорошая совместимость

## Требования к безопасности

### Доступы
- [ ] Отдельный пользователь Union (read-only)
- [ ] Отдельный пользователь 1С (ограниченные права)
- [ ] Шифрованное соединение (TLS)

### Логирование
- Все операции записываются
- Хранение логов 90 дней
- Уведомления об ошибках

### Бэкап
- Перед любым импортом — снимок БД 1С
- Возможность отката

## MVP (минимальный продукт)

### Scope
1. Экспорт новых бронирований из Union (1 раз в день)
2. Создание "Поступление на счет" в 1С
3. Уведомление бухгалтеру в Telegram

### Не входит в MVP
- Real-time синхронизация
- Обработка изменений/отмен
- Полный документооборот
- Двусторонняя синхронизация

## Зависимости и риски

### Зависимости
| Зависимость | От кого | Критичность |
|-------------|---------|-------------|
| Доступ к Union | Бэкофис | Высокая |
| Доступ к 1С | Бухгалтер | Высокая |
| Структура данных Union | Вендор | Высокая |
| Версия 1С | Бухгалтер | Средняя |

### Риски
| Риск | Вероятность | Митигация |
|------|-------------|-----------|
| Union не имеет API | Средняя | Альтернативные методы экспорта |
| 1С не поддерживает импорт | Низкая | Разработка обработки |
| Расхождение данных | Средняя | Сверка + алерты |

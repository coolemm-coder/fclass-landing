## НАЙДЕННЫЕ ПРОБЛЕМЫ (по критичности)

### 🔴 КРИТИЧНО: Ссылки идут через automation.landingpro.by (redirect mismatch)

**Что происходит:** Все ссылки в письме (включая fclass.by) на самом деле ведут через:
```
https://automation.landingpro.by/webhook/email-click?eid=...&url=https://fclass.by...
```

**Почему это убивает доставляемость:**
- Спам-фильтры видят несоответствие: текст ссылки = `fclass.by`, но href = `automation.landingpro.by`
- Это классический паттерн фишинга — **главный триггер спам-фильтров**
- automation.landingpro.by — неизвестный домен без репутации
- Gmail, Outlook, корпоративные фильтры это МОМЕНТАЛЬНО помечают как spam

**Решение:** Убрать click-tracking через automation.landingpro.by. Ссылки должны вести напрямую на fclass.by с UTM-метками. Если нужен click-tracking — использовать поддомен fclass.by (например, `track.fclass.by`), а не чужой домен.

### 🔴 КРИТИЧНО: Логотип закодирован в base64 прямо в HTML

**Что происходит:** В `<img src="data:image/png;base64,...">` вставлен PNG логотип размером ~30KB.

**Почему это проблема:**
- Размер HTML письма: 33KB+ (рекомендуется < 15KB)
- Многие email-клиенты БЛОКИРУЮТ data URI изображения
- Спам-фильтры флагают письма с embedded base64 как подозрительные
- Это удваивает "вес" каждого письма

**Решение:** Разместить логотип на `fclass.by` как обычный файл:
```html
<img src="https://fclass.by/email/logo.png" alt="First Class" height="48">
```

### 🔴 КРИТИЧНО: Тяжёлый HTML шаблон для холодного outreach

**Что происходит:** Письмо — полноценный HTML-шаблон с:
- Таблицами для layout
- Фоновыми цветами (#0c1825, #c9a962)
- Inline CSS на каждом элементе
- Хедер + футер + подпись = визуально как маркетинговая рассылка

**Почему это проблема:**
- Gmail автоматически определяет такие письма как "Промоакции" (CATEGORY_PROMOTIONS)
- Корпоративные email-серверы (Exchange, Zimbra) часто блокируют HTML-рассылки
- Целевая аудитория — корпоративные клиенты с жёсткими спам-фильтрами
- **Подтверждение:** тестовые письма на coolemm@gmail.com уже попадали в CATEGORY_PROMOTIONS

**Решение:** Для холодного outreach использовать PLAIN TEXT или минимальный HTML:
```
Добрый день!

Пишу вам, потому что {company_name} работает на международных рынках...

[текст без HTML-форматирования]

--
Надежда
First Class | fclass.by
+375 44 772-52-66
```

### 🟡 ВАЖНО: Трекинг-пиксель через automation.landingpro.by

**Что происходит:**
```html
<img src="https://automation.landingpro.by/webhook/email-track?eid=...&a=open" width="1" height="1">
```

**Проблемы:**
1. Домен automation.landingpro.by неизвестен — это дополнительный сигнал для спам-фильтров
2. Многие email-клиенты блокируют внешние изображения по умолчанию
3. Корпоративные прокси часто блокируют запросы к неизвестным доменам
4. **Результат:** даже если письмо доставлено — open-tracking не сработает

**Решение:**
- Трекинг через поддомен: `track.fclass.by/pixel?eid=...`
- Или использовать профессиональный сервис (Unisender, SendPulse) со встроенным трекингом

### 🟡 ВАЖНО: Проверить DNS записи fclass.by

Я не смог проверить DNS из этого окружения. **Нужно проверить вручную:**

```bash
# В терминале Mac:
dig TXT fclass.by +short
dig TXT _dmarc.fclass.by +short
dig MX fclass.by +short
```

**Что должно быть:**
- **SPF:** `v=spf1 include:_spf.mail.ru ~all` (или аналог для Mail.ru)
- **DKIM:** запись от Mail.ru в DNS
- **DMARC:** `v=DMARC1; p=none; rua=mailto:dmarc@fclass.by`

Без SPF/DKIM/DMARC — письма с Mail.ru будут отклоняться ВСЕМИ серьёзными почтовыми серверами.

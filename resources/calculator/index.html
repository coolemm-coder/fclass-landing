Методика расчета

  • Условия по договору — тариф, сервисный сбор, отсрочка и документы согласуются до выписки билетов; фиксированный процент экономии заранее не обещаем.
  • Часы бухгалтера на одну командировку: сотрудник покупает сам = 1.5 часа (компенсация + проверка чеков + ЭСЧФ + авансовый отчёт), разовые счета = 1.0 час (счёт + платёж + ЭСЧФ + закрытие), уже есть другой договор = 0.2 часа (только акцепт акта в конце месяца).
  • С договором для юрлиц любой модели = 0.2 часа на командировку (приём билета + закрытие в конце месяца).
  • Ставка бухгалтера — брутто-зарплата ÷ 168 рабочих часов в месяце. По умолчанию 25 BYN/ч (≈ зарплата 4 200 BYN до налогов).
  • Не учитывается: потеря НДС-вычета при покупке сотрудником, время руководителя на согласование разовых платежей, риск налоговой проверки разовых счетов.
  • Подробнее о механике договора — в материале договор на авиабилеты для юрлиц или в бесплатном PDF-шаблоне.
